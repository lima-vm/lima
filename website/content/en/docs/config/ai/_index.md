There are two kinds of scenario to use Lima with AI:

- [AI agents inside Lima]({{< ref "/docs/config/ai/inside" >}}): running an AI agent **inside** a VM
- [AI agents outside Lima]({{< ref "/docs/config/ai/outside" >}}): calling Lima's MCP tools from an AI agent running **outside** a VM
